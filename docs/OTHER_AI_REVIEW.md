## 价值判断

| 改动 | 实际用途与判断 |
|---|---|
| `send / reply` | 有价值。让 agent 用现有消息通道完成提问、进度和结果回复，避免自行拼接 Markdown；不能把 from 字段当作身份认证或授权。 |
| `archive` | 有价值。已处理历史可以离开实时队列，减少扫描和消息摘要；须保留未完事项、未读回复与交接引用。 |
| 范围漂移 | 有价值。提示任务开始后出现、但没有登记的改动，帮助发现漏报范围；不能证明修改者或据此收回占用。 |
| CI 与依赖固定 | 有价值。Ruff、编译检查和完整 Actions SHA 提供可复核门控；依赖更新应进入 develop，编译缓存应在源码之外。 |
| 未使用 import、lambda 与字符串整理 | 行为基本不变。可保留为配合 Ruff 的小修正，不应作为功能优化或性能提升的证据。 |

## 已修复的问题

- **消息续活缺失**：新增 send/reply 命令未加入活动白名单，每次调用会返回活动更新失败。现在与 archive 一同加入固定命令清单，仍只记录命令名、不记录正文或参数。
- **旧身份写入**：身份检查发生在等待锁之前，会话结束后仍可能用旧身份发送。现在写前、锁内及替换前核对真实记录、分支和重复 ID；已结束、损坏或不属于当前会话的身份拒绝写入。
- **回复覆盖原要求**：原实现重新读取但没有核对完整旧字节，可能覆盖外部刚修改的内容；还会归一化 BOM/换行或把围栏内的回复标题当作分界。现在保留原结构和模式位，比较稳定快照与原要求版本，无法可靠分界时保留现场。
- **过早完成事项**：reply 默认 answered 会让“收到、正在检查”关闭人类任务。现在默认 open，写入实际完成结果时显式 `--status answered`；可带 `--request-version` 拒绝针对旧要求的回复。回复不能重新激活已经解除的人类控制。
- **归档吞掉有效消息**：只检查 created 会把刚回复的旧问题移走；旧计划在消息重新变成 open 后仍能执行，还可能破坏别的 worktree 或未完交接。现在仅归档当前工作区，创建/回复/最后修改均须超期，保留控制、未答、未读回复与未结束会话引用，等待锁及移动前复核原版本。
- **归档失败和同名风险**：批次中后一步失败会留下不完整移动，POSIX rename 可能覆盖并发出现的目标。现在使用不覆盖目标的移动方式，本批失败尝试逆序回滚，外部修改阻止回滚时明确报告保留位置。
- **归档入口超限死循环**：实时扫描超过 4096 条后要求归档，但归档也使用同一个受限入口。现在归档使用独立有界历史扫描，默认每批 100 条；明细按预算裁剪，完整计数保留。预览零写，实际应用需要自己的明确会话身份。
- **漂移错误和旧快照复用**：错误类型 JSON 使看板崩溃，activate 写快照失败会复用旧任务，Git 扫描失败被当成空集，旧脏文件后续新改动也被忽略。现在校验类型/版本/容量，以独立随机标识绑定任务并记录文件元数据；缺失或失败关闭明细，保留占用，Git 失败不报告无改动。
- **测试与 CI 契约问题**：修正真实旧日期夹具的 mtime、纯查询的 `--no-activity` 及显式完成回复；基线标识使用独立随机源，不消费会话 ID 冲突测试的 UUID。compileall 缓存写 runner 临时目录，Dependabot 指向 develop 并合并有限依赖批次。

## token 与使用边界

消息正文仍按需读取；send/reply 只输出结果元数据及相关短提示，避免把原正文重新塞入上下文。范围检查只展开前 5 个路径和完整总数，归档批量与输出有界。历史过多时归档减少实时扫描量，预览裁剪采用批量缩减，避免每移除一条都重新序列化整份输出。

漂移检查需要额外的 Git status 和文件元数据查询，只在有可用基线的任务上执行，每个工作区一次；不逐个读取业务正文。相同大小、mtime 等元数据的内容变化可能不可见，提示不能证明修改者。旧基线保留兼容，基线失败不会放宽占用门禁。

字符预算不等于模型账单。可选 tokenizer 缓存缺失，精确 tokens 仍为 null；本轮未声称精确 token 节省比例。归档后的阅读回执不自动清除，长期使用仍需核对回执容量。

首次 Windows 浏览器控制连接超时，复试时其 native pipe 仍不存在；随后用 REA 连接 Chrome 的本机 CDP 端口并运行独立浏览器场景，完成截图与交互验收。首个选择器多匹配、预览到时关闭和连接模式视口不一致均保留为未通过的尝试；最终独立浏览器场景使用唯一选择器和正确视口，捕获完整、没有页面错误或错误级 console 事件，临时浏览器正常退出。只关闭本任务创建的标签，隔离预览服务已停止，原协作记录内容和修改时间未变。

浏览器证据保存在私有 `browser-retry-evidence-final.json` 和 `browser-retry-verification.json`，包含桌面、手机与待机截图的摘要和 SHA256；截图文件为 `browser-retry-desktop-final.png`、`browser-retry-mobile-final.png` 和 `browser-retry-standby-final.png`。本次只复验界面及补充本报告，核心工具与已通过回归的源码未改。

本地运行时验收覆盖 Windows / Python 3.12 和 Linux / Python 3.14；其它系统与 Python 组合由功能分支推送后的远端 selftest 矩阵验证。本报告记录本地审核完成时的结果，远端矩阵结论需核对对应提交的 Actions 运行。
