01WHAT它是什么

AI 各干各的， 规矩只有一套。

它不是又一个 AI 编排器 —— 不负责启动 AI、不给每个 AI 隔离工作区（那是 Claude Squad、Conductor 这类工具的活）。 它管另一半：让已经在同一个项目里干活的多个 AI 会话互相可见、守同一套规矩、听你指挥。

PILLAR 01

一份规则总章

AGENTS.md / CLAUDE.md 是每个 AI 开工前的必读：先协调再干活、分支怎么切、测试怎么算过、人类指令优先级最高。六个平台各读各的入口，规则只写一遍。

PILLAR 02

一块共享黑板

.agents/ 就是本机共享记忆：谁在哪个分支干什么、心跳还活不活、有问题问谁、前任走了怎么接手。全是几个 Markdown 小文件，不进 git，切分支不丢。

PILLAR 03

一个看板脚本

tools/agents_status.py 零第三方依赖。AI 用它跑一行摘要做开工协调；你用它开网页指挥台——实时看每个 AI 状态，直接对它下指令。

03SOP四条交规

四条交规， 写在 AGENTS.md 里。

RULE 01 · 文件纪律

各写各的小文件，不共用大文件

一个会话一个 session 文件、一天一份 worklog、一个问题一张 inbox 留言条，天然不撞车；万一两个会话同时写了同一个文件，合并时取并集——只多不少。

RULE 02 · 判活方式

用心跳判断死活，不用锁

锁在 AI 崩溃时会永远卡死。心跳超过 15 分钟算失联；别人想接手，先在 inbox 发接管声明、等 5 分钟无人反对，并保留前任的全部提交。

RULE 03 · 交叉验证

看板上没人 ≠ 真的没人

忘了注册会话的 AI 是隐形的。除看板外，还要交叉看 git reflog、文件 mtime、有没有构建进程在跑——三个信号都对上才下手。

RULE 04 · 数据边界

协作文件只留本机，不进 git

写进 .git/info/exclude：切分支不丢、不会误提交、不污染团队仓库。代价是没有云端备份——重要节点把 .agents/ 拷到仓库外即可。

2 分钟前 5 分钟前 11 分钟前 14 分钟前 ≥ 15 分钟

心跳长这样：绿色脉冲 = 会话还活着；灰点静止 = 已失联，别人可以在 inbox 声明接管。 跑长任务的 AI 会在 session 文件里写明「预计 HH:MM 回来」，超时才判失活。

04TOWER你的指挥台

AI 看文件， 你看网页。

  • 01每 5 秒自动刷新。每个 AI 一张卡片：哪个平台、在哪个分支、做什么任务、几分钟前还有心跳（绿 = 正常，红 = 失联）。
  • 02问题与交接一眼可见。未答复的 inbox 留言、前任留下的「下一步 / 阻塞点」，不用去翻文件。
  • 03worktree 告警。有 AI 在没登记过的目录里动了手脚，红色告警直接拍在页面上。
  • 04直接对 AI 下指令。在卡片上输入「先停一下，别碰登录模块」——AI 在下个阶段间隙读到并执行，回复实时回到网页，可开桌面通知。人类指令优先级最高。
  • 05三档安全。默认只听本机；局域网可以只读大屏，或设密码后可指挥——「对外可写又无密码」的组合会被拒绝启动。
terminal · powershell / bash
# 你和 AI 都能用看板；--web 开图形化指挥台

# 不开服务，只把当前状态存成单文件快照（零外链，可发给别人）

# AI 开工协调用的一行摘要（输出短、省 token）

06GO三十秒上手

三十秒， 立好交规。

前提只有两个：电脑装了 Python 3.8+ 和 git，项目是 git 仓库。 安装器幂等，你定制过的内容（测试命令、构建命令）升级时自动保留。

发给项目里任意一个 AI
帮我把 multi-agent-collab 套件装到当前项目。
套件仓库地址：https://github.com/AiFLYF/multi-agent-collab
1. 先确认 python 和 git 都能运行；不能运行就停下告诉我，不要自行安装任何软件。
2. 电脑里还没有这个仓库就先 git clone 上面的地址；已经有了就跳过。
3. 确认当前目录是我的项目根目录，执行 python <套件目录>/install.py install .；
   成功后再执行 python <套件目录>/install.py doctor .，把体检结果原样发给我。
除安装器生成的文件外不要动项目里的其他文件，任何报错先停下来问我。
  • AI 会自己 clone、安装、跑体检，把结果发给你——不想敲命令的人用这种
  • 用 fork 的话，把提示词第二行的地址换成你的 fork
terminal
# 装进任意 git 项目（幂等；先看会改哪些文件不落盘，把 install 换成 install --dry-run）
$ python install.py install /path/to/your-project

# 体检：文件、忽略规则、版本新旧、看板冒烟
$ python install.py doctor /path/to/your-project

# 改完 AGENTS.md 总章后，刷新 WorkBuddy 入口镜像
$ python install.py mirror /path/to/your-project

  • 不想跑脚本想手工拷贝：README 里有等价的 cp 命令清单

装完之后（3 分钟）

  1. ① 打开项目里的 AGENTS.md 第 6 节，把示例换成你项目真实的测试 / 构建命令（定制区，升级自动保留）
  2. ② 在项目目录跑一次 python tools/agents_status.py --web，确认看板正常
  3. ③ 新开一个 AI 对话，问它「你开工前要先做什么」——应答出：先看板、查 inbox、再干活，说明规则已生效

✓ 适合

  • 同一台电脑、同一个 git 工作区
  • 多个 AI 会话（含真人）同时干活
  • 不想搭任何服务器、任何账号
  • 和 Claude Squad / Conductor 这类编排器叠加使用

? 想清楚再用

  • 跨电脑协作（需要真正的远程同步，本工具刻意不做）
  • AI 之间要毫秒级实时通信（这里最快是「下次工具调用时读到留言」）
  • AI 完全不遵守 AGENTS.md（退回最朴素规矩：同一时间一个 AI 动一个文件）
  • 想把 AGENTS.md 提交进仓库全团队共享（本套件取舍：规则本机私有、各自定制）
